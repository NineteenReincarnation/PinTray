---

**PinTray** 是一款轻量级窗口置顶工具，适用于 Windows 11。它常驻系统托盘，方便随时将需要的窗口保持在最前面。

## 主要功能

- 置顶或取消置顶窗口，支持同时置顶多个窗口。
- 支持的窗口会在右上侧边缘显示小图钉，点击即可切换置顶。
- 也可通过全局快捷键切换置顶，默认 `Ctrl + Alt + P`，支持修改。
- 支持开机自启，界面跟随 Windows 主题和首选显示语言（未提供译文时使用英文）。

## 运行要求

- Windows 11 x64。
- 安装版和独立运行版无需额外安装运行时。
- 从源码构建需要 Visual Studio C++ 工具链。
